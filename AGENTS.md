# Physics Lab - AI Project Rules

## 1. Project Purpose
Physics Lab is a physics experiment and science knowledge website for students.
The website helps students understand physics concepts, experimental principles, equipment, procedures, and scientific applications.

## 2. Language
- All website content must use Traditional Chinese (繁體中文).
- Use clear and simple language suitable for university students.
- Explain scientific terms accurately.

## 3. Design Style
- Use a clean, modern, academic design.
- Main colors: dark navy, white, and light blue.
- Use readable fonts and clear spacing.
- The website must support desktop and mobile screens.
- Keep the layout consistent across all pages.

## 4. Website Structure
- index.html: Homepage
- experiments.html: Physics experiments
- concepts.html: Physics concepts
- equipment.html: Experimental equipment
- css/style.css: Website styles
- js/main.js: Website interactions
- images/: Website images

## 5. Page Content Rules
Every experiment page should include:
1. Experiment title
2. Introduction
3. Experimental purpose
4. Experimental principle
5. Equipment
6. Experimental procedure
7. Results and discussion

Science concept pages should include:
1. Concept introduction
2. Important formulas
3. Explanation of variables
4. Practical applications

## 6. File Naming Rules
- Use lowercase English filenames.
- Use hyphens to separate words.
- HTML files must use the .html extension.
- CSS files must be placed in the css folder.
- JavaScript files must be placed in the js folder.
- Images must be placed in the images folder.

## 7. AI Development Rules
- Always read this AGENTS.md before modifying the project.
- Follow the existing design and folder structure.
- Do not delete existing content without permission.
- Reuse existing CSS styles whenever possible.
- Keep HTML, CSS, and JavaScript in separate files.
- Check all links and navigation after making changes.
- Do not introduce unnecessary libraries.
- Make sure the website works on mobile and desktop.

## 8. Future Development
When adding a new experiment or science topic:
- Follow the existing page layout.
- Use the same colors, fonts, and navigation.
- Include accurate scientific explanations.
- Add links to the new page from the homepage or relevant category page.
- Keep the content organized and easy to understand.
